# LUMEN Academy

Application éducative interactive consacrée au code, aux sciences et au projet LUMEN de réalité augmentée pour la basse vision.

## Contenu

- Feed de 75 cartes pédagogiques
- Choix d'un thème précis ou mode Mix
- C++, Python, JavaScript, HTML, CSS, React, Vite, Redux et TypeScript
- Async, API et DevOps
- Circuits électriques, physique et chimie
- Progression, XP, cartes maîtrisées et sauvegardes stockées dans le navigateur
- Parcours LUMEN, prototype, bibliothèque, business, investisseurs, succès et journal

## Ouvrir localement

Ouvrez simplement `index.html` dans un navigateur récent.

## Publier avec GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Ajoutez tous les fichiers de ce dossier à la racine du dépôt.
3. Ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche `main` et le dossier `/ (root)`.
6. Enregistrez. GitHub affichera ensuite l'adresse publique du site.

Aucune installation, commande npm ou compilation n'est nécessaire : l'application est contenue dans `index.html`.

## Stockage des données

Les progrès sont enregistrés avec `localStorage`. Ils restent donc sur l'appareil et le navigateur utilisés. Effacer les données du navigateur remet la progression à zéro.
