# Mise en ligne rapide sur GitHub Pages

## Méthode sans terminal

1. Sur GitHub, cliquez sur **New repository**.
2. Donnez-lui un nom, par exemple `lumen-academy`.
3. Choisissez **Public**, puis créez le dépôt.
4. Cliquez sur **uploading an existing file**.
5. Glissez dans GitHub tous les fichiers présents dans ce dossier.
6. Cliquez sur **Commit changes**.
7. Allez dans **Settings → Pages**.
8. Choisissez **Deploy from a branch**.
9. Sélectionnez `main` puis `/ (root)` et cliquez sur **Save**.

L'adresse sera normalement de la forme :

`https://VOTRE-NOM.github.io/lumen-academy/`

Le fichier principal doit impérativement rester nommé `index.html`.
